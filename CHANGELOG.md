# Changelog

All notable changes to Framework Charge Limit are documented here.

## 1.0.0 — 2026-08-10

- adopt the stable `com.github.vojtabiberle.frameworkchargelimit` widget ID,
- add one-shot charging to 100% with automatic battery-care restore on unplug,
- persist pending restore state across Plasma restarts, suspend, and reboot,
- add udev and systemd integration for restore events,
- add English source strings and a complete Czech translation,
- add GitHub Actions validation, package artifacts, and tagged releases,
- add a standalone launcher and dedicated Task Manager icon,
- add README screenshots and public installation documentation.

## 0.5.0 — 2026-08-10

- add gettext localization infrastructure and Czech translations,
- add rendered Plasma light-theme screenshots,
- fix the public clone instructions.

## 0.4.2 — 2026-08-10

- add author and project metadata,
- make the distributable `.plasmoid` a valid ZIP archive.
